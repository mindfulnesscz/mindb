# Code map

Line numbers change; search by symbol. Comments are useful, but executable branches and database policy
remain authoritative.

## Pipeline

`pipelineService.ts` is a 92-line orchestrator; each stage is its own module under
`desktop/src/services/pipeline/`.

| Question | Primary implementation |
|---|---|
| What does pressing Run actually mean? | `desktop/src/features/pipeline/runPlan.ts` (pure, tested) |
| What happens around a run? | `desktop/src/features/pipeline/useRunPipeline.ts` |
| Which files are scanned, in what order? | `services/pipeline/scan.ts`, `collect.ts` |
| Why was a thumbnail created or skipped? | `services/pipeline/thumbnails.ts`; Rust `generate_thumbnail` |
| How does R2 deduplicate? | `src-tauri/src/r2.rs` (`upload_to_r2`) |
| How are CDN object keys built? | `services/pipeline/cdnUpload.ts`, `storageKey.ts` |
| What stops a run deleting everything? | `services/guardrail.ts` (`assessDestruction`) |

## Identity and sync

`supabaseService.ts` is a barrel over `desktop/src/services/supabase/`.

| Question | Primary implementation |
|---|---|

| How are assets synchronised? | `services/supabase/assetExport.ts` → `exportIdentify` → `exportPlan` → `exportWrite` → `exportDisconnect` |

| How is a new package and draft scaffolded? | `desktop/src/features/vocabulary/createAssetFolder.ts` |
| How do requests authenticate? | `services/supabase/rest.ts` (`makeHeaders`, `sbFetch` 401 retry) |
| Where is desktop CDN GC controlled? | `features/settings/CdnGarbageCollectionCard.tsx`, `services/supabase/cdnGarbageCollection.ts` |

## Cloud storage

One module per provider under `desktop/src/services/cloud/`.

| Question | Primary implementation |
|---|---|
| How does connecting work? | `cloud/oauth.ts` (PKCE), `features/cloud/connectDest.ts` (flow + cancellation) |
| Why is OneDrive different? | `cloud/onedrive.ts` — device code, not a loopback redirect; rotates its refresh token |
| Which drive or folder is targeted? | `cloud/onedrive.ts` (`graphDriveBase`), `cloud/gdrive.ts` (folder walk) |
| Why was an upload skipped? | `cloud/gdrive.ts` — same name and size means unchanged |
| Where is the Rust side? | `src-tauri/src/cloud.rs` (Dropbox chunked sessions) |
